# Changelog

All notable changes to this project will be documented in this file.

## [2.1.1] - 2026-07-15

### Fixed
- Updated completed material detection to use the site's current icon color
- Improved supplementary material detection by matching the icon type suffix
- Included extension icons in the Firefox release archive

### Changed
- Changed releases to run only for explicitly pushed version tags
- Removed obsolete automatic synchronization from `main` to the `v2` branch
- Updated build dependencies

### Changed
- Updated build system with esbuild
- Updated dependencies to latest versions

## [2.0.0] - Initial Release

### Added
- Automatic video playback for school study sites
- Chrome extension setup
